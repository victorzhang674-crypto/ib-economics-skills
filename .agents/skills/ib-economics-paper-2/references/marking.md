# Paper 2: analytic marking and the data-response band

Source: IB Diploma Programme *Economics guide*, first assessment 2024, printed pp. 59–62, 64–65 and 74–75. The guide publishes the general bands; the exam-specific markscheme is separate.

## Parts (a)–(f), /25 combined

- Grade each subpart against its own printed maximum. Use the exact markscheme for acceptable answers, diagram and explanation credit, alternative methods, and any own-figure or rounding guidance. Accept an equivalent answer when it meets the applicable scheme. Never assume one point per feature, a universal unit penalty, or automatic carry-forward credit.
- Without that scheme, explain what is economically correct and what the command term still requires. For a calculation, distinguish formula, input selection, arithmetic and interpretation. For a diagram, distinguish the model and labels from the explanation of how they apply to the extract.
- If a source or table is missing, do not guess the figures, award data credit by inference, or treat unavailable work as a confirmed blank.

## Part (g), /15

Apply the band holistically; use question-specific guidance if available. Within the best band, choose an integer based on the strength and consistency of the evidence. Evaluation and source use both matter.

| Band | What the answer demonstrates |
| --- | --- |
| 0 | No evidence reaches the lowest band. |
| 1–3 | Little engagement with the task; theory and terms miss the issue, evaluation is absent, and the material is ignored or simply copied. |
| 4–6 | Some grasp of the task; describes relevant theory with some appropriate terms. Draws only a little on the material and offers superficial evaluation. |
| 7–9 | Covers part of the task with partly explained theory and some accurate language. Includes any suitable diagram where appropriate, draws on some relevant source details, and evaluates with limited balance. |
| 10–12 | Answers the task with explained theory and appropriate terminology. Explains relevant diagrams where appropriate, applies the source generally well, and gives a mostly balanced evaluation. |
| 13–15 | Addresses all demands with fully explained theory, consistently appropriate terms, and thorough explanation of appropriate diagrams. Applies specific text or data to build a reasoned argument with effective, balanced evaluation. |

Give feedback that distinguishes reporting a number, explaining what it implies, and using that implication to weigh an option. For instance, if the data show high public debt, ask whether the answer explains how this might constrain a proposed fiscal expansion and what evidence would make that constraint more or less binding.
