# IB Economics Paper 2

First assessment 2024. The same paper is used at SL and HL; no HL extension content. Choose one data-response question from two and answer its subparts. Time: 1 hour 45 minutes, plus five minutes of reading time. Calculator permitted. Total /40; weight: 40% SL, 30% HL.

| Part | (a) | (b) | (c)–(f) | (g) |
| --- | ---: | ---: | ---: | ---: |
| Marks | 4 (2 + 2) | 5 | 4 each | 15 |

Use the printed allocations; (b) may split 3 + 2 or 2 + 3. Parts (a)–(f) are marked with the question-specific scheme; (g) is a holistic response using markbands and question-specific guidance.

## Mark a response

Read [the Paper 2 marking reference](references/marking.md). Align the question, extracts, tables, answer and supplied markscheme to the same question. Report evidence and an actionable correction per attempted part. For (g), identify which source details actually do work in the argument; copying a figure or line does not show application. Without the matching markscheme, label short-part marks as estimates and do not invent an official point split. If material is missing, give feedback on what is visible, and flag any judgment that depends on the missing source or diagram. Give /40 only for a whole-question review or when explicitly reporting a full attempt with identified blanks.

## Plan or write a practice answer

- **(a)–(f):** Match depth to the command term. For calculations, set up the formula, substitute values, show the result and use the units, base or rounding the question calls for. For a diagram-plus-explanation item, draw the requested model and explain why the cited event moves the relevant curve or changes the outcome in that context.
- **(g):** Decide what the question asks you to judge. Select evidence from the supplied materials and turn it into a chain: source detail → relevant theory → predicted consequence → why it affects the judgment. Cite the extract or table as identifiable in the paper. Compare the most consequential trade-offs using context such as stakeholder effects, policy constraints, or time horizons. End with a supported judgment. Outside examples can supplement the source when useful; the given text and data still need to support the argument.
- For timed practice, reserve about 40 minutes for (g), about 60 for (a)–(f), and 5 for checking. If creating an original practice task, supply the extracts or data needed to answer it and clearly label synthetic material.
