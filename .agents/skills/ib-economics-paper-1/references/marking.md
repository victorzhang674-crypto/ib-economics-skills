# Paper 1: guide markbands and feedback

Source: IB Diploma Programme *Economics guide*, first assessment 2024, printed pp. 59–64 (format and markbands), 74–75 (command terms). The tables paraphrase the general markbands. A matching exam's separately published markscheme supplies question-specific guidance; for example, it clarifies which mechanisms, diagrams or examples address that question. These tables are not a points checklist or an official markscheme for an individual question.

## Part (a), /10

| Band | What the answer demonstrates |
| --- | --- |
| 0 | No evidence reaches the lowest band. |
| 1–2 | Barely engages with what is asked; the theory and terms offered are off topic. |
| 3–4 | Shows some grasp of the task; describes relevant theory and introduces some appropriate vocabulary. |
| 5–6 | Covers only part of the task; explains some of the mechanism and uses some terms correctly. Includes a suitable diagram where useful. |
| 7–8 | Addresses the task and explains the relevant mechanism. Terms are mostly well used, and any appropriate diagram is connected to the explanation. |
| 9–10 | Answers the full task with a developed causal explanation, consistently accurate terminology, and a thorough explanation of any appropriate diagram. |

## Part (b), /15

| Band | What the answer demonstrates |
| --- | --- |
| 0 | No evidence reaches the lowest band. |
| 1–3 | Barely engages with the task; theory, vocabulary and any example are off target. No meaningful weighing of the issue. |
| 4–6 | Identifies some of what is asked, describes relevant theory and names a relevant example. Some relevant vocabulary; any evaluation is superficial. |
| 7–9 | Answers part of the task with partial explanation and some accurate terms. Uses a suitable diagram where appropriate. The example is partly connected to the question; evaluation is relevant but one-sided. |
| 10–12 | Addresses the task with explained theory, mostly appropriate terminology, and explanation of relevant diagrams where appropriate. Develops a real case in context and weighs the issue with reasonable balance. |
| 13–15 | Covers the full task and explains the theory and any appropriate diagrams fully, with accurate terms throughout. A developed real case supports the argument, and the answer weighs competing considerations effectively. |

## Make the mark actionable

1. Compare the answer with adjacent bands. Place it where the evidence fits overall, then use the lower or upper end of that band according to consistency and depth. Apply any question-specific rules in the matching markscheme. Avoid inventing a fixed diagram penalty or dividing the marks into arbitrary categories.
2. Check whether a diagram explains the requested mechanism: the change in the curve or constraint, the result at the new equilibrium, and why that result matters. If the question explicitly calls for a diagram, flag its absence; do not assume a diagram is required for every answer.
3. For (b), distinguish naming an example, explaining what happened, and using the case to support or qualify the answer. “A tax raises prices” is analysis; explaining how inelastic demand in the named market shifts more of the burden to buyers, and why that changes the equity judgment, is evaluation if supported by the case.
