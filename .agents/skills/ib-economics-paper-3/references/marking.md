# Paper 3: analytic marking and the recommendation band

Source: IB Diploma Programme *Economics guide*, first assessment 2024, printed pp. 58–62, 65–66 and 74–75. The guide publishes the general bands; the exam-specific markscheme is separate.

## Part (a), /20 per question

Grade each subpart against its own maximum. Match formulae, method, results, diagrams and explanations to the question-specific scheme. Credit alternate valid methods and apply own-figure rules only as supported by that scheme. If a numerical result is wrong, find where the reasoning first departs from the task. Check that the student used the correct base, scale and units, and distinguish arithmetic from any interpretation the question asks for. Without the scheme, explain these differences and label any mark as provisional.

## Part (b), /10 per question

Mark holistically using the best-fit band and any matching question-specific guidance. Credit a defensible, context-appropriate policy supported by theory and evidence. Do not apply invented mark deductions or require a diagram, exact number of arguments, or a second policy unless the question or scheme calls for it.

| Band | What the answer demonstrates |
| --- | --- |
| 0 | No evidence reaches the lowest band. |
| 1–2 | Names a policy but does not support it with theory or source evidence, uses irrelevant terminology, and offers no evaluation. |
| 3–4 | Picks a suitable policy and includes some relevant terminology, but uses theory only superficially. No relevant source evidence supports it and evaluation is thin. |
| 5–6 | Explains a suitable policy with some correct terminology. Theory gives partial support; source details provide limited backing and the evaluation is one-sided. |
| 7–8 | Fully explains a suitable policy, uses relevant theory and mostly accurate terms, applies the source generally well, and weighs the case with reasonable balance. |
| 9–10 | Fully explains a suitable policy. Theory, accurate terms and relevant source evidence work together to support the recommendation, with effective, balanced reasoning. |

Test whether the stated constraint would change the recommendation. For example, if a source indicates that essential imports are driving inflation, explain whether tighter monetary policy would mainly dampen domestic spending or also ease imported inflation through the exchange rate; weigh that against effects on output and employment. Treat this as an illustration of reasoning, not a predetermined policy answer.
