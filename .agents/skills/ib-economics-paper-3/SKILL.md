# IB Economics Paper 3

First assessment 2024. HL only. Answer both compulsory questions, each with short subparts in (a) worth /20 combined and a policy recommendation in (b) worth /10. Total /60; weight 30%. Time: 1 hour 45 minutes, plus five minutes of reading time. Calculator permitted. Questions can draw on all four syllabus units, including HL extensions.

## Mark a response

Read [the Paper 3 marking reference](references/marking.md). Align the question, source material, answer and any supplied markscheme. For each (a) subpart use the matching scheme, including its allowances for alternative methods and errors where stated. If unavailable, label marks as estimates and do not invent a point split. For each (b), choose a best-fit band and integer mark, explain what the context contributes to the recommendation, and identify the most useful revision. Where data or a diagram is missing, mark only what can be supported and flag the limitation. Report /30 per complete question; use /60 for the full paper, with any confirmed blanks distinguished from missing material.

## Plan or write a practice answer

- **(a):** For quantitative questions, show the setup, substitution, result and relevant units or rounding. Interpret the result where asked. For qualitative questions, follow the command term and the specific context instead of assuming every subpart is a calculation.
- **(b):** State one clear, feasible policy recommendation that addresses the named problem. Use economic theory to explain the transmission mechanism and tie it to relevant text, data or a usable result from (a). Weigh the strongest benefit against a meaningful limit, cost or implementation risk in that context. End by explaining why the policy is advisable on balance and any condition that materially affects that judgment. Consider an alternative only if the comparison sharpens the recommendation; several policies are not a requirement.
- For timed practice, use about 50 minutes per question and 5 to check. To write an original mock, include enough source information for both the calculations and the policy judgment and label synthetic material.
